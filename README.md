# HYPASS Android App

App name: HYPASS
Website loaded in app: https://hypass.in
Tagline: TRAVEL. EXPLORE. EXPERIENCE.

This is a native Android WebView wrapper project prepared for Android Studio.
It includes the supplied HYPASS logo and launcher configuration.

## Build the Play Store AAB
1. Open this folder in Android Studio.
2. Let Gradle sync and install any requested Android SDK components.
3. Select Build > Generate Signed Bundle / APK.
4. Choose Android App Bundle (AAB).
5. Create/select your release keystore and build the release bundle.
6. Upload the resulting .aab to Google Play Console.

Application ID: in.hypass.app
Version: 1.0 (versionCode 1)

Before publishing, complete the Play Console listing, privacy policy, data safety form,
content rating, screenshots, app icon requirements, and signing configuration.
